# Agent Instructions

This project tracks work with **GitHub issues**. Use `gh issue list` / `gh issue view <n>` to find and inspect work, and close issues via PR or `gh issue close <n>`.

`bd` (beads) was retired per [cadence-groundwork#138](https://github.com/cameronsjo/cadence-groundwork/issues/138). The `.beads/` directory is dormant data left over from when it was in use — it is not the work queue and should not be treated as one.

## Session Completion

Wrap up normally: run quality gates, commit, push, and open a PR as needed. If you're using cadence, `cadence:outro` covers this.
